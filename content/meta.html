The Architecture of the Architecture

0. The Living Dossier: CadPlan as the Master Specification

Why this application is the specification: combining multi-granular agent prompts, interactive laboratories, vector compass components, and code references.

The Dual-Audience Master Living Specification Engine

In traditional software engineering, architectural specifications are static PDF documents or wiki pages that quickly rot and diverge from actual code. When developers collaborate with large language models, this creates confusion: developers copy-paste fragmentary prompt instructions or snippets, leading to hallucinated geometric methods, Catmull-Rom approximations, or broken coordinate models. What makes CadPlan extraordinary is the sheer sophistication of the product specification itself. It is not a speculative wish list. It is an executable living blueprint that unifies a complete AutoCAD baseline with AccuDraw's 3D spatial superpowers, providing an immense, mathematically grounded payload that an AI can ingest and immediately construct without guesswork.

The core architectural vision is centered on democratizing proven CAD tools through AI acceleration:

1. The Expandable Dual-Mode Tool: People have built AutoCAD clones, but nobody thought to build a new tool that does both: it seamlessly drops into classic AutoCAD mode if you want it to, but can instantly expand into this really smart AccuDraw spatial mode. Users adopt it with zero workflow shock, then discover single-keystroke 3D planes, squircle compasses, and on-curve splines.

2. AI as the Engine Builder: This is not about speculative autonomous AI drafting—it is about using AI to rebuild and synthesize a proven, multi-billion-dollar CAD tool and make it accessible to everyone. A solo developer, equipped with domain experience and an exhaustive living specification, can now build what once took an army of graphics programmers decades to assemble.

3. Zero Token Fragmentation: Because every class, mathematical audit, and interactive laboratory is self-contained in this dossier, an LLM receives 100% of the system context in one coherent payload, turning the specification itself into the ultimate engineering prompt.

Methodology Why The Whole Specification Is Delivered Together
  • The Expandable Dual-Mode Tool: Drops into 100% AutoCAD baseline mode for familiar 2D commands, prompts, and DXF/DWG compatibility; expands into AccuDraw/SmartLine 3D mode with kinetic compasses, on-curve relaxation, and single-stroke shortcuts.
  • AI Building the Tool for Everyone: Breaks down the barrier to entry so a solo inventor can democratize enterprise CAD power, bypassing $10,000/seat legacy licensing.
  • Unrivaled Specification Sophistication: Every mathematical equation (direction cosines, closest-point tangent arc swings, bulge factors) is explicitly solved. Feeding this dossier into an LLM provides an immense, verifiable payload that enables rapid, error-free code generation.

The Living Document as the Ultimate Technology Showcase

A core tenet of my engineering philosophy is that this document must aggressively showcase as much of our technology as humanly possible. When engineers write specifications, they typically produce passive text, static diagrams, and dry API tables. That is fundamentally obsolete. Because we have absolute ownership and control over the codebase and the presentation layer, the document itself is a live, high-fidelity gallery of our entire technological stack: Luno Workspace, Aardvark, the ColorPicker, the CurveDrawer, and CAD spatial engines—including AccuDraw and SmartLine—running concurrently in both procedural SVG and hardware-accelerated Three.js WebGL.

Rather than burdening every chapter with the full, heavy accuCad workstation, our architecture creates focused, interactive sub-views that showcase specific subsets of capability:

1. The Animated Compass Choreography: A dedicated viewport where the compass is wired to an automated animation loop—demonstrating single-stroke 3D plane rotations (Top, Front, Side), polar-to-rectangular superellipse morphing, and axis-locking pulses without distracting drawing geometry.

2. The Deconstructed Squircle Laboratory: An interactive view derived from our standalone Squircle app that draws the radial projection lines to the centers of all 8 circular arcs, highlighting the exact tangency junction dots.

3. Extensible Custom Cursor Showcase: A pluggable demonstration that replaces the standard AccuDraw reticle with an intricate steampunk brass mechanical indicator, proving that our cursor HUD is an open, extensible plugin layer.

Showcase Architecture Showcasing the Full Suite: Luno, Aardvark, ColorPicker, & AccuDraw

  • 2. Aardvark: Universal element inspection, electric blue semantic recognition, and in-situ commenting.
  • 3. ColorPicker: RYB hue ring and barycentric tint/shade triangle controlling live 3D PBR materials.
  • 4. SliderControl: Continuous variable scrubbing with direct numerical valuation popups and MIDI-CC mapping.
  • 5. CurveDrawer: On-curve G1 through-point relaxation and low-pass kinetic string dragging.
  • 6. AccuDraw & SmartLine: 3D direction cosines, closest-point tangent arc swings, and universal DXF bulge factors.

Rethinking Prompt Engineering: The Living Specification Loop

This architecture fundamentally rethinks the entire concept of prompt engineering. Traditional prompt engineering is a brittle exercise in writing repetitive chat prompts, hoping an LLM understands your architecture from memory. Our approach is vastly superior: the running application IS the prompt, and the prompt IS the running application. The human author interacts directly with the live document. You read the technical text, test the interactive laboratories, and use Aardvark to attach living directives and voice notes directly to specific paragraphs, canvas stages, or DOM elements. The system packages the entire state—including exact DOM XPath locators, code contexts, and author ideas—into an immense, mathematically grounded prompt bundle.

The next major milestone is Deep Luno Interconnection with Universal Free-Form Comments. Instead of keeping document notes isolated in local dialogs, any comment, sketch, or voice directive attached to any paragraph, diagram, or canvas will push directly into Luno's Outbox. Luno acts as an in-process continuous development engine: the human author tours the living specification, attaches free-form thoughts anywhere across the DOM, and with one tap dispatches an aggregated prompt bundle to the AI. The AI streams back surgical class method and HTML template patches, and Luno compiles them straight into local files in real time.

AI Methodology The Human-in-the-Loop Living Specification Cycle
  • 1. Interactive Review: The inventor reads the technical dossier and tests live interactive viewports.
  • 2. Universal Annotation: Aardvark pins directives directly to specific paragraphs, diagrams, or DOM nodes.
  • 3. Automated Outbox Compilation: CadPlan compiles all notes, XPaths, and code contexts into a single payload.
  • 4. AI Spec Refinement: The LLM refines the architectural specification, resolving edge cases and updating chapters.
  • 5. Client-Side Splicing: Luno merges surgical class method and HTML template patches with zero token waste.

Inverted Luno Integration: In-Process Panel & Zero-Iframe Mandate

To maximize performance and developer flow, we are inverting the relationship between Luno and the documentation: instead of embedding CadPlan inside an iframe within Luno, CadPlan embeds Luno natively. Within CadPlan, there are no nested iframes. All 3D viewports, SVG laboratories, and documentation sections run in-process within the same DOM and WebGL memory context. When you want to inspect Luno, queue outbox payloads, or review git checkpoints, you tap a dedicated 🌙 Luno cockpit button in the header. Luno slides open as an in-process control drawer directly in the active window. You maintain a unified workspace on desktop without window juggling, while mobile phone companion surfaces remain cleanly decoupled over WebRTC.

Container Inversion The Zero-Iframe Mandate & In-Process Cockpit Drawer
  • 1. In-Process Execution: Eliminates all iframes inside CadPlan; 3D viewports and DOM share single-thread V8 heap.
  • 2. Native Luno Cockpit Drawer: Tapping '🌙 Luno' in the header slides out the Luno control deck as a native UI drawer.
  • 3. Zero-Latency Communication: Direct method calls between CadPlan and OutboxQueue with zero postMessage serialization.
  • 4. Decoupled Mobile Companion: Desktop workspace remains consolidated, while smartphone trackpads connect over low-latency WebRTC.

The Anti-Redundancy Mandate: Single Source of Truth & Modular Instruments

A core architectural invariant of this codebase is absolute non-redundancy. In many software projects, developers create simplified mock-ups or duplicate parallel versions of core algorithms for individual demos—such as writing an ad-hoc 3D compass in a demo component that reorients on Q using fabricated math, rather than running the authentic AccuDraw compass from accuCad. This is strictly forbidden. There is only one authentic accuCad. Rather than spawning duplicate implementations, our architecture requires that every demonstration, lab, and viewport draws directly from the exact same modular source files (SquircleArc.js, AccuDrawLogic.js, RoundingUtils3D.js, KeyCommandHandler.js). If a component needs to show a specialized subset—such as an isolated view of the compass or an on-curve spline—it must configure and render that subset using the original production classes.

This modular reusability extends across the entire ecosystem. Components such as ColorPicker.js (with its RYB hue ring and barycentric tint/shade triangle) and SliderControl.js (with direct numerical entry and inertia wheels) are used inside accuCad, but they are built as general-purpose instruments. Because they are modular, we can instantiate and test them independently anywhere on the web, embed them throughout documentation chapters, and wire them directly to our low-latency mobile TouchController trackpad deck over local Wi-Fi. Every tool stands on its own, shares the single source of truth, and eliminates duplicate code maintenance.

Engineering Invariant The Anti-Redundancy & Reusability Mandate
  • Single Source of Truth: Never create duplicate or mock versions of core CAD math (SquircleArc, AccuDraw, RoundingUtils3D). Every lab or demonstration mounts the authentic modular class with tailored options.
  • Modular Component Hierarchy: Instruments like ColorPicker and SliderControl are general-purpose building blocks shared across CAD, UI, and mobile touch surfaces. Viewports can isolate a specific subsystem while maintaining 100% mathematical fidelity.
  • True Outbox Integration: Actions labeled 'Send to Outbox' communicate directly with Luno's OutboxQueue across iframes and windows rather than simply dumping text to the clipboard.

Next Thread: Extreme accuCad Embedding, Animated Micro-Demos & Document-First Architecture

The primary mandate of the upcoming engineering thread is to take accuCad native embedding to the absolute extreme. We are not building passive documentation with static images or toy mock-ups. When people open this living specification, they must be completely knocked over by how alive, interactive, and hyper-sophisticated it is.

The document serves a dual purpose: first and foremost, it communicates directly with a human audience—the author, peer engineers, and prospective open-source collaborators—grounding them in proven spatial ergonomics. Simultaneously, it acts as an exhaustive, verifiable engineering prompt for autonomous AI coding agents. It lays out the definitive architectural blueprint for software that will be written partly by the author and partly by the global developer community using this specification.

Instead of forcing users to navigate to an external tab or launch a heavy workstation to understand a concept, every single chapter will feature a live, animated in-process accuCad micro-demo that immediately demonstrates the exact topic of that page in motion.

As soon as you switch to Chapter 1 (Origins), the 3D compass rotates into Top, Front, and Side orientations while placing a 3D isometric bracket. On Chapter 3 (accuCad Audit), the demo displays 50ms chorded tentative snapping with live Mini-Jack projection lines. On Chapter 4 (Shortcuts), single-keystroke commands execute without <Enter>. On Chapter 5 (Curve Drawer), splines dynamically interpolate through on-curve points. Each demo runs a scripted "ghost drafter" animation loop that continuously showcases the ergonomics. Crucially, if the user moves their mouse over the canvas, the scripted loop smoothly yields, giving the user immediate, interactive command of the real 3D drafting engine.

Interaction Engine The Autonomous Choreography & Takeover Protocol
  • Dedicated Scripted Scenarios: Each page declares an automated interaction script demonstrating its specific capability (Plane Turning, Smart Locking, Chord Snapping, Spline Tensioning).
  • Ghost Drafter Virtual Cursor: An animated SVG reticle simulates exact mouse trajectories, data clicks, and chord snaps at 60 FPS.
  • Seamless Human Takeover: Hovering or clicking anywhere inside the active canvas pauses the animation loop, transfers keyboard routing to the human drafter, and allows unrestricted live CAD drawing.
  • Single Source of Truth: Scenarios are NOT ad-hoc animations; they dispatch real data points directly through BaseController and AccuDrawLogic.

A centerpiece of the next thread is showcasing the authentic Curve Drawer to the extreme. For forty years, the commercial CAD industry has tortured users with off-curve Bézier handles. In our engine, we demonstrate Rob Brown's proven alternatives directly in the live viewports.

We will showcase both distinct curve modalities concurrently: Modality 1 (On-Curve Through-Points) with real-time 8-iteration $G^1$ tangent relaxation, vertex-targeted curvature fullness, and chord balance; and Modality 2 (The Kinetic Tether / String-Drag) where pressing Ctrl extends an elastic tow rope to filter out hand micro-tremors, while pressing Shift backtracks along the path to interactively undo and re-aim. Every segment drawn in the canvas automatically generates real AutoCAD DXF bulge factors $\text{bulge} = \tan(\theta/4)$, demonstrating zero-loss round-tripping with CADCraft and legacy DWG workflows.

Curve Mathematics On-Curve Relaxation & Kinetic Tether Dynamics
  • Modality 1: On-Curve Through-Point Relaxation: Click anchors strictly ON the curve itself. UpdateControlPoints.js derives exact cubic Bézier control points iteratively with vertex-targeted curvature and balance.
  • Modality 2: Kinetic String-Drag (Tether): Holding Ctrl extends elastic dashed string; releasing pulls curve tip; holding Shift interactively scrubs backward along trajectory to undo mistakes.
  • SmartLine Continuous Fillet Fallback: If setback exceeds half the segment length, renders a clean sharp corner without interrupting the drafter.
  • Closest-Point Sweep: Solves tangent arc orientation by evaluating proximity to candidate circumference, sweeping smoothly from +5° to -6° with zero deadband jitter.

The next thread firmly establishes our Document-First Architecture. The document is the primary deliverable—it is not trapped inside Luno, nor does it require booting Luno just to read or annotate.

Anyone can load CadPlan as a standalone web app. As you read, you can attach voice directives, text thoughts, or bug reports to any paragraph, table, or 3D canvas using Aardvark. Every note receives our animated crawling-ants outline and is stored safely in browser IndexedDB. When you want to edit the specification or compile an AI prompt, tapping an edit link or 🌙 Luno slides open the Luno development cockpit in-process. The stored notes are bundled into Outbox payloads, dispatched to the AI, and when the patch returns, our resolution protocol automatically retires the notes and clears the crawling ants.

Architecture Document-First Workflow (Zero-Luno Friction)
  • 1. Standalone Document Load: The living spec loads instantly in any browser without server dependencies or Luno dev bloat.
  • 2. Universal Annotation: Aardvark pins voice notes and text directives to any DOM node, highlighting them with crawling ants.
  • 3. Safe Persistence: Directives persist in IndexedDB across reloads until explicitly resolved or compiled.
  • 4. On-Demand Luno Cockpit: Tapping '🌙 Luno' opens the in-process cockpit drawer to review checkpoints and queue Outbox payloads.
  • 5. Automated Retirement: The AI returns patches with resolution metadata, clearing notes and chiming audio acknowledgment.

To enable dozens of live accuCad viewports across the dossier without crashing browser WebGL context limits (typically 8–16 simultaneous contexts), the next thread implements an intelligent multi-instance GPU lifecycle.

Using IntersectionObserver, viewports that scroll off-screen automatically pause their rendering loops and suspend requestAnimationFrame updates, reducing GPU memory and power consumption to near-zero. Furthermore, our Centralized Keyboard Router guarantees that only the single on-screen canvas currently hovered or interacted with captures single-stroke shortcuts (T, F, S, V, L, Space, O), preventing shortcut cross-talk while keeping the desktop experience lightning-fast.

  • 2. Seamless Takeover Handshake: Human cursor interaction pauses choreography and gives full manual drafting control.
  • 3. Curve Drawer Deep Showcase: Dynamic on-curve through-point relaxation, kinetic string dragging, and DXF bulge factors.
  • 4. GPU Context & Lifecycle Optimization: IntersectionObserver suspension for off-screen viewports.
  • 5. Unified Keyboard Router: Context-aware single-stroke key capture isolated strictly to the active canvas.
  • 6. Document-First Decoupling: Standalone reading & annotation without loading Luno, with 1-click in-process cockpit sliding.
