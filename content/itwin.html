4. AccuDrawHintBuilder: The standardized protocol whereby interactive CAD drawing tools communicate contextual intent to the compass—such as anchoring origin to the prior vertex or aligning orientation to the current stroke segment.

5. SavedState: A transactional state stack that allows AccuDraw to push and pop coordinate frames across view manipulation and nested sub-commands.

The SmartLine Continuous Chaining State Machine

In 1994, alongside AccuDraw, I invented SmartLine. Prior to SmartLine, CAD users were forced to draw individual straight lines, circles, and arcs using separate disconnected tools, manually trimming intersections and using fillet commands to round corners afterwards. SmartLine combined all linear geometry into a single continuous gesture. Within SmartLine, there are two distinct kinds of arcs: Rounded Corner Fillets and Independent Tangent Arc Segments. If a rounded corner could do it, that's what was done. Crucially, for corner fillets, if a segment was too short to physically fit the requested rounding radius, SmartLine simply rendered a clean, sharp corner. It did not distort the drafter's requested radius, push adjacent vertices, or interrupt the user with modal error dialogs. The geometry stayed clean, predictable, and fast.

Arc segments were remarkably easy to make tangent to the previous segment because AccuDraw automatically oriented itself with the tangent vector of the prior line. Crucially, as soon as you switched into Arc mode, AccuDraw flipped into Polar mode, letting the draftsperson immediately type the radius or chord distance directly without looking at a command prompt. SmartLine arc segments are governed by Rob Brown's Closest-Point Sweep Principle: the orientation is solved by finding the candidate tangent arc where the cursor is as close as possible to a point along the circumference. As you pull the mouse away, the arc naturally opens out from 0° to +5°; if you back up and cross the tangent line, it smoothly flips to -6° with zero deadband jitter. Upon committing the arc, the compass automatically aligns to the exit tangent vector, allowing the draftsperson to continue tangent or perpendicular into the next segment effortlessly.

State Machine SmartLine Continuous Geometry Transitions
  • Type A: Rounded Corner Fillets: Tangent circular arc connecting incoming and outgoing segment bisectors. Short-Segment Fallback renders a clean sharp corner if setback exceeds half segment length.
  • Trailing Corner Live Adjustment: Closing a loop applies active fillet radius to $P_0$, keeping a live adjustment hook until a new command begins.
  • Type B: Tangent Arc Segments: Closest-Point heuristic evaluates proximity to candidate circumference with zero deadband jitter.
  • Exit Tangent Orientation: Compass aligns to exit tangent vector automatically upon arc commit.
  • Single-Stroke Escapes: T, F, S, or V snaps compass back to orthogonal planes without breaking polyline chain.

To bring this interaction model into the modern open ecosystem, we implement the entire 2D drafting engine in pure SVG. In the live laboratory above, you can lay down lines, press A or ~ to swing dynamic tangent arcs, watch the Squircle Compass rotate to align with exit tangents, and press T or V to break onto standard planes. Each segment drawn in the SVG canvas maps 1:1 into CADCraft's LwPolyline with PolyVertex { point, bulge: tan(θ/4) }.

Surface Normal Alignment (Q), Transactional Undo & winit Key Interception

A primary capability proven in our accuCad prototype is Instant Surface Normal Alignment (Q). When drafting in 3D, a user clicks or tentative-snaps onto an angled face of a 3D solid or imported assembly, and taps Q. The compass immediately tilts flush against that surface. The challenge in 3D space is that a face hit provides only a single vector: the surface normal $\vec{n}$. To construct a stable drafting plane, we derive two orthogonal tangent vectors ($\vec{X}_c, \vec{Y}_c$) using Gram-Schmidt orthogonalization without gimbal lock or sudden axis flipping as the camera moves.

Gram-Schmidt Math 3D Face Normal Derivation & Non-Flipping Axes

Derives stable, non-flipping 3D drafting axes from a surface hit normal $\vec{n}$. Selects a reference up vector to avoid collinear cross products, normalizes $\vec{X} = \text{up} \times \vec{n}$, and derives $\vec{Y} = \vec{n} \times \vec{X}$, feeding directly into CADCraft's Mat4::ocs.

To preserve continuity between AutoCAD and AccuDraw, we synchronize their state stacks. In CADCraft, drawing operations commit changes to cadcraft-doc::EntityStore with incremental transaction IDs. In compassdraw-core, we maintain a parallel SavedState stack. Whenever an entity point is committed, AccuDraw records its floating origin, active ThreeAxes, and coordinate locks. If the user invokes AutoCAD's UNDO command, CADCraft notifies CompassDraw, which pops its state stack to the matching transaction ID—instantly returning the compass origin and working depth to the prior vertex.

Event Interception Single-Stroke Typing & Smart Backspace in winit
  • Numeric Interception: Numbers are captured directly into the active field buffer without opening command-line prompts.
  • Smart Backspace: Truncates active typing buffer or least significant digit of live dynamic coordinate.
  • Zero Double-Typing: Eliminates keystroke conflicts between AccuDraw and CADCraft.

Fillet Geometry: CADCraft Newton-Raphson vs. Analytic Bisector

Our inspection of CADCraft's crates/geom/src/fillet.rs reveals a sophisticated numerical solver. Rather than just supporting simple circular arc fillets between straight line segments, CADCraft's CornerFit computes circles tangent across any combination of Lines, Circles, Ellipses, and Splines (TanCurve) using a 40-step damped Newton-Raphson method on exact offset curves.

By contrast, in accuCad/js/RoundingUtils3D.js, our 3D path filleting algorithm is closed-form and analytic: it calculates the 3D angle bisector between incoming and outgoing unit vectors, directly projecting tangent touch points $p_1$ and $p_2$. This is ultra-fast ($O(1)$) and works across arbitrary 3D planes. By combining both approaches, compassdraw-core uses analytic 3D bisectors for real-time mouse hover previews, and CADCraft's Newton solver for complex spline/ellipse boundary fillets.

Algorithm Audit CornerFit (Rust) vs. RoundingUtils3D (JS)
  • CADCraft (fillet.rs): Damped Newton-Raphson solver supporting lines, circles, ellipses, and NURBS splines.
  • accuCad (RoundingUtils3D.js): Closed-form 3D vector bisector math ($O(1)$ speed, zero iterations) optimized for 60 FPS cursor previews.

SmartKeyin: Directional Sign Inference & SavedState

One of the most elegant interaction design details in AccuDraw—preserved in Bentley's AccuDraw.ts under public smartKeyin = true—is automatic directional sign inference. When drafting precisely, forcing a user to type -12.5 versus 12.5 based on Cartesian signs breaks drafting rhythm. Your eyes are on the geometry, not on coordinate signs.

In AccuDraw.ts, when smartKeyin is active, the engine checks whether the current cursor delta vector points along the negative axis: this._xIsNegative === (this.delta.x >= 0.0). If the user moves the mouse to the left and types 5, AccuDraw automatically multiplies the value by -1. The sign is inferred entirely from physical human motion. Furthermore, AccuDraw.ts maintains savedStateViewTool and savedStateInputCollector: when the user pans, zooms, rotates the view, or runs a nested query command, AccuDraw pushes its coordinate frame to a state stack, restoring origin, locks, and orientation without resetting the active drawing command.

Math & State Stack SmartKeyin Quadrant Inference & SavedState
  • delta.x < 0.0 ? -abs(val) : abs(val): Eliminates 100% of negative key-ins during drafting.
  • savedStateViewTool: Restores active compass frame after view manipulation (Pan, Zoom, Orbit).
  • savedStateInputCollector: Preserves origin and locks across nested measurement tools.

MCP Autonomous Drafting & Compass Constraints

CADCraft includes cadcraft-mcp—a native Model Context Protocol server. Currently, AI agents interact with CADCraft using raw absolute coordinates (e.g. create_line(x1, y1, x2, y2)). Anyone who has watched an LLM draft knows the problem: models struggle with exact spatial trigonometry, producing misaligned corners, small gaps, and overlapping lines.

By exposing CompassDraw endpoints to the MCP server (compass_origin, compass_align, compass_lock_axis, smartline_segment), the AI agent drafts using relative vectors: "Move origin to vertex A, lock X-axis, offset 42.5 units, tangent arc of radius 10 to vertex B." This allows the AI agent to produce geometrically perfect, manifold drawings on the first pass without spatial hallucinations.

Agent API Model Context Protocol Compass Endpoints
  • compass_set_origin(handle, vertex_index): Anchors compass to an element vertex.
  • compass_orient_plane(plane): Sets Front, Top, Side, or element normal.
  • compass_vector_input(distance, angle | dx, dy): Commits constrained displacement.
  • smartline_chain(points, radii, auto_close): Commits multi-segment tangent path.

compassdraw-core: The Headless Rust Crate

To bridge our interaction design into CADCraft and the broader Rust CAD ecosystem, we are blueprinting compassdraw-core—a standalone, pure-Rust crate with no_std compatibility that compiles to native desktop binaries (macOS Metal, Windows DX12, Linux Vulkan via winit/wgpu) as well as WebAssembly. The crate contains zero UI, windowing, or DOM allocations. It takes ray origins, ray directions, and key codes, and returns constrained coordinates, direction-cosine matrix bases, and arc bulge factors.

Because compassdraw-core is decoupled from both the GPU and windowing systems, it satisfies both requirements simultaneously:

1. 2D Drafting Replacement: In 2D mode, it locks the projection plane to Top ($Z=0$), converting 3D ray intersections into 2D planar coordinates ([x, y, 0.0]) that feed directly into CADCraft's standard Vec2 command machines.

2. 3D Spatial Navigation: In 3D mode, single-keystroke inputs (T, F, S, V, Q) reorient ThreeAxes, allowing PlineM and CADCraft's Mat4::ocs to extrude angled faces with exact topological continuity.

3. Dual Host Support: The same crate feeds CADCraft's native wgpu overlay pass on desktop and drives Three.js / WebGL viewports via our host.rs postMessage bridge on the web.

Rust Architecture compassdraw-core Crate Specification
  • ThreeAxes: Direction cosine basis ($x, y, z$) managing spatial orientation.
  • CompassDraw: Kernel state machine managing origin, locks, roundoff, and SmartLine chaining.
  • no_std compatible: Zero heap/OS bindings for ultra-portable execution in Wasm or microcontrollers.
