13. Modular Lego Architecture & File Map

How Basic3D, Library/CadModules, single-command loading, cooperative keyboard scopes, and document/iframe embeds fit together like Lego bricks.

This viewport uses CadModules.embed(...) and slice.registerCustomCommand('pin', ...) to attach a brand-new 3D Pin command directly onto ThreeJSLoader + AccuDraw + TentativePointHandler + scoped KeyCommandHandler—without loading DrawRectangleCommand, DrawPathCommand, or any of the other built-in tools.

Where Everything Lives (Verified File Map)

Instead of keeping all CAD features trapped inside the monolithic accuCad app folder, the reusable Lego pieces now live inside Library/ and load dynamically on demand. Apps like Basic3D stay lean at startup and do not require AccuDraw or CAD tools to be preloaded or even present unless requested.

Directory Topology Core Lego Modules & Responsibilities
  • Library/CadModules.js: Canonical dynamic slice loader (getSliceManifest, getToolManifest, loadToolSlice, mountOnThreeJSLoader, embed). Loads from Library/cad/ with automatic fallback to accuCad/js/.
  • Library/cad/: Standalone CAD slices (AccuDraw.js, Squircle3D.js, accudraw/AccuDrawLogic.js, TentativePointHandler.js, SmartDrawKeys.js, EventHandlers.js, elements/*, commands/*).
  • Library/ThreeJSLoader.js: Base WebGL viewport with auto-updating Line2 resolutions on resize and threeApp.loadAccuDraw(options).
  • Library/KeyCommandHandler.js: Cooperative multi-scope shortcut router (createScope, setActiveScope, window.blur cleanup) that yields to host pages, inputs, Aardvark, and sibling widgets.
  • Basic3D/Basic3d.js: Minimal 3D host with lazy buttons for AccuDraw, per-tool CAD loading, TouchController, inline document mode, and iframe URL/postMessage API.

Composable Recipes: Slices, Single Tools & Iframes

Every capability can be snapped in independently: just the AccuDraw compass + cooperative keyboard, a single built-in tool via slice.loadTool('rectangle'), a single custom command via slice.registerCustomCommand(...), or wireless phone pairing via slice.loadTouchController(tray).

Integration Patterns 4 Ways to Feature 3D & CAD in Documents or Apps
  • 1. Single Built-In Command: await threeApp.loadAccuDraw({ tool: 'rectangle', keyboard: true, wheelZoomMode: 'when-focused' }) loads only RectangleElement and DrawRectangleCommand.
  • 2. Single Custom Command: slice.registerCustomCommand('pin', handler, { hotkey: 'p' }) wires AccuDraw constraints + snapping into your own tool.
  • 3. Zero-Boilerplate Document Embed: await CadModules.embed(el, { primitives: true, tool: 'curve' }) includes IntersectionObserver off-screen GPU pause and automatic cleanup.
  • 4. Iframe Embed + URL Params: Load /Basic3D/index.html?accudraw=1&tool=rectangle&inline=1&viewMode=smart-drag or drive via postMessage (basic3d:loadAccuDraw, basic3d:loadTool, basic3d:setPlane, basic3d:setViewMode, basic3d:setKeyboard).

Conflict-Free View Controls & Next-Thread Handoff

To avoid overloading Shift (which Basic3D uses for Shift-paint) or fighting Left-Click data points, EventHandlers and CadModules distinguish clicks (< 5px) from drags (>= 5px) and expose explicit navigation and wheel-zoom options.

Handoff Checklist View Modes & Next-Thread Priorities
  • viewMode: 'smart-drag' (Default): Left-Click = Draw, Left-Drag = Orbit, Right-Click = Reset, Right-Drag = Pan, Left+Right 50ms Chord = Tentative Snap.
  • viewMode: 'middle-right': Left-Click always draws; Right-Drag = Orbit; Middle-Drag = Pan.
  • viewMode: 'modifiers': Alt+Drag = Orbit; Shift+Drag = Pan.
  • wheelZoomMode: 'always' (standalone), 'when-focused' (in scrollable documents), or 'alt'.
  • Next Thread Priorities: Keep Library/cad/* synced with accuCad/js/* (or retire duplicate app copies), break out CadStorageManager (DXF/JSON) and ViewControls sliders as optional Lego slices.
